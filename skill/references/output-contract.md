# 完整输出契约

在生成完整图片提示词与换装视频方案时读取。模式 B 的参数推荐阶段和模式 D 的局部改造不需要套用完整契约。

## 1）参数锁定结果

只列本次真正使用的参数，不机械输出空字段。用户明确参数标记为 `用户锁定`，自动补全项集中列在 `系统补全`。

```markdown
## 参数锁定结果
- 角色：
- 成年年龄感：
- 国籍 / 族裔外观：
- 外貌锚点：
- 发型 / 头饰 / 耳饰：
- 初始主造型：
- 造型1：
- 造型2：
- 造型3：
- 造型4：
- 拼贴布局：
- 图片比例：
- 视频比例：
- 视频时长：
- 镜头：
- 动作基调：
- 换装机制：
- 换装卡点：
- 声音：
- 系统补全：
```

## 2）首帧图片提示词

输出一段可直接用于图像模型的完整提示词，不要只给关键词。必须包含：

- 画幅、摄影任务、人物数量和拼贴结构
- 同一成年人物的身份与外貌锚点
- 中央人物和每个小人物的位置、姿态及服装
- 白色虚线轮廓、背景、光线、镜头和材质
- 为视频重合换装保留的身体拓扑与动作空间
- 无文字、品牌、Logo 和水印要求

## 3）逐段视频时间轴

使用 Markdown 表格。每次换装单独占一行，开场和结尾展示也各占一行。

```markdown
## 逐段视频时间轴
| 时间 | 当前造型 | 动作与眼神 | 换装触发与运动 | 完成点与动作延续 | 衣料物理 | 声音 |
|---|---|---|---|---|---|---|
| 0.00–... | 初始造型 | ... | ... | ... | ... | ... |
```

时间段必须连续且不重叠。完成点与参数锁定结果完全一致；最后一段必须给最终造型留出展示时间。

## 4）精简视频提示词

输出一段适合直接粘贴到视频模型的连续文本，包含：

- 继承首帧的人物、服装、布局、比例、镜头和光线
- 按时间顺序写出的动作、触发方向和换装完成点
- 换装前后的姿态、重心、眼神和衣料连续性
- 所选机制不可省略的因果约束

使用 M1 时必须明确：飞入的是完整人物副本；原位置贴图立即移除并留空；副本与中央人物对齐后消失；中央最终只保留一个人物。

## 5）负面提示词 / 强制约束

输出一段可直接附加到生成请求的负面提示词。至少覆盖：

- 人物变脸、年龄变化、族裔外观变化、发型或配饰漂移
- 第六人物、矩形缩略图、贴图残留、中央双影或残影
- 服装叠穿、错误肢体、多余手指、身体融合、头部裁切
- 动作重置、衣料穿模或僵硬漂浮、背景突变、意外运镜
- 文字、品牌、Logo、水印

## 交付前自检

- 五项内容齐全，或明确说明当前属于模式 B / D
- 所有用户锁定参数在五项内容中一致
- 人物数量、服装数量、时间段和换装次数互相匹配
- 图片提示词中的小人物位置与视频触发方向一一对应
- 未声称已经生成未实际生成的图片或视频
