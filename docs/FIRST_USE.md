# 首次使用教程

## 1. 最简单的调用方式

在请求开头写出 Skill 名称，然后描述人物、服装方向和视频要求：

```text
$female-outfit-director
帮我为同一位中国成年女性设计五套现代都市修身穿搭，生成9:16拼贴首帧提示词和8秒卡点换装视频脚本。
```

未指定参考图、国籍或族裔外观时，Skill 默认使用原创中国成年女性角色，并在参数和提示词中明确写出。

## 2. 使用人物参考图

上传一张清晰人物图并输入：

```text
$female-outfit-director
参考上传图片的人物五官、脸型、发型和气质，保持同一位成年角色，设计五套学院风穿搭，并输出首帧提示词和换装视频时间轴。
```

Skill 会优先使用参考图中清晰可见的信息，不会用默认人物覆盖参考人物。

## 3. 先要方案，再生成完整脚本

如果还没决定风格，可以先让 Skill 推荐：

```text
$female-outfit-director
先推荐5组差异明显的女性换装主题和参数组合，暂时不要生成完整提示词。
```

选定方案后继续说：

```text
选择方案3，生成完整的首帧图片提示词、视频时间轴、精简视频提示词和负面提示词。
```

## 4. 指定换装方式

可以直接指定某种机制，例如：

```text
$female-outfit-director
使用M1消耗式贴图换装：点击后复制完整人物贴图飞入中央并放大，原位置贴图立即消失，完成换装后飞入副本也消失。
```

M1 的标准过程是：

1. 点击一个目标小人物贴图。
2. 复制出的完整人物抠像向中央飞入并放大。
3. 原位置贴图立即移除，原位置留空。
4. 飞入人物与中央人物姿态对齐并触发换装。
5. 飞入副本及其虚线轮廓消失，只保留中央换装后的一个人物。

每使用一次贴图，四周可用贴图就减少一个。因此它属于“贴图消耗式换装”，不是贴图永久保留式切换。

## 5. 自定义时长、动作和音乐

用户参数会覆盖默认值。例如：

```text
$female-outfit-director
生成15秒舞蹈换装视频。人物始终位于中央，安排转身、剪刀手、比心、踏步和定格动作；四次换装严格落在2.8秒、5.7秒、9.2秒、12.4秒，使用明亮电子流行卡点背景音乐。
```

也可以只修改某项内容：

```text
保留人物、服装、布局和时长，只把换装机制改成M8贴纸翻页与M10动作卡点交替。
```

## 6. 一次完整输出包含什么

默认会得到：

1. 参数锁定结果：明确人物、服装、布局、时长、镜头、动作、换装和声音。
2. 首帧图片提示词：用于生成同一人物的多套穿搭拼贴母图。
3. 视频时间轴：逐段说明动作、触发、飞入方向、完成时刻、服装物理和音效。
4. 精简视频提示词：适合直接复制到视频生成模型。
5. 负面提示词和强制约束：避免人物变脸、贴图残留、重影、肢体错误和镜头突变。

完整生成任务会按上述顺序交付五项内容，并在交付前检查时间段连续性、造型数量和贴图位置对应关系。参数推荐阶段或仅修改换装机制时，只输出当前阶段需要的内容。

## 7. 提高成功率的写法

- 明确人物必须为成年人。
- 明确哪些人物特征必须保持不变。
- 每套服装尽量写清款式、颜色、材质和层次。
- 短视频建议只使用 1 至 2 种主要换装机制。
- 如需精准卡点，直接给出每次换装完成的秒数。
- 如果强调动作连续性，请写明换装前后不得重置姿势、重心和旋转方向。
- 对 M1 明确写出“原位置贴图立即消失、中央只保留一个人物”。

## 8. 可直接复制的首次请求

```text
$female-outfit-director
请使用原创中国成年女性角色，视觉年龄24岁，自然写实东亚面部特征。设计5套现代都市穿搭，保持同一张脸、同一发型、同一身材比例。生成9:16五人拼贴首帧：中央为初始造型大人物，四周为四个完整小人物贴图。视频8秒、固定机位，采用M1消耗式贴图换装；每次点击后复制人物贴图飞入中央并放大，原位置贴图立即消失，重合换装后副本消失。请完整输出参数锁定结果、图片提示词、逐段时间轴、精简视频提示词和负面提示词。
```
